Work

Websites built for real small-business jobs.

Each project is a fully working demo for a fictional Melbourne business. I picked three common types of local business and built what each one needs most.

01 · Café · Middle Park VIC

Little Tern Café

A neighbourhood café that wanted fewer phone calls about opening hours, and a way for regulars to order coffee before they arrive.

  • HTML
  • CSS
  • JavaScript
  • Responsive
Open live demo →

The problem

Customers kept calling to ask if the café was open. Weekend queues were long, and people left before ordering.

What I built

  • Order-ahead cart with pickup times
  • "Open now" badge using Melbourne time
  • Table booking with day, time and guests
  • Photo menu with dietary labels
  • Gallery with full-screen viewer

The result

Hours, menu and booking are one tap away on a phone. Orders can be ready before the customer walks in, which shortens the morning queue.

02 · Trades · Bayside VIC

Kestrel Plumbing & Gas

A family plumbing business that needed more quote requests from its website, and fewer "how much will it cost?" calls.

  • HTML
  • CSS
  • JavaScript
  • File upload
Open live demo →

The problem

Visitors couldn't tell if the business worked in their suburb or roughly what a job would cost, so they called competitors instead.

What I built

  • Instant price estimator in the first screen
  • Suburb and postcode checker
  • Quote form with photo upload
  • Phone number validation for AU numbers
  • Sticky "Get a quote" button on mobile

The result

Customers see a price range and service area in seconds, then send a quote request with photos. The plumber knows the job before calling back.

03 · Fitness · South Melbourne VIC

Southpaw Social Boxing

A small boxing gym with a bold brand that wanted more free-trial sign-ups and a timetable members actually use.

  • HTML
  • CSS
  • JavaScript
  • Web Audio
Open live demo →

The problem

The timetable was a photo of a whiteboard. New people didn't know which class to try first.

What I built

  • Timetable with day tabs and spots left
  • Round timer with a bell for home training
  • Weekly / fortnightly price toggle
  • 3-step free-class booking
  • Programs with difficulty levels

The result

Visitors see today's classes first and book a free class in three taps. The round timer gives members a reason to come back to the site.
